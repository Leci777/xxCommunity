# xxCommunity
以前的课设——**小区物业管理系统**，WinForms + SQL Server。业主信息、报修、收费、停车、公告、投诉反馈都能管，带登录注册。

```
登录 ──► 主界面 ─┬─ 业主 / 小区信息
               ├─ 报修 / 投诉反馈
               ├─ 收费管理
               ├─ 停车管理
               ├─ 公告管理
               └─ 用户 / 系统设置
                    │
                    ▼
              SQL Server（脚本在 database/）
```

## 快速开始

### 1. 建数据库
先执行 `database/小鑫小区物业管理系统.sql`，把库和表建好。

### 2. 打开项目
VS 打开 `小鑫小区物业管理系统.sln`（.NET Framework 4.7.2，VS2019+）。

### 3. 配数据库连接
启动后如果连不上库，设置界面里可以改连接字符串（也可以直接改 `App.config`）。

### 4. 登录
没有内置账号，自己注册一个；或者往数据库的用户表里插一条。


## 常见问题

- **连不上数据库**：挨个确认——SQL Server 开着吗、SQL 脚本执行了吗、连接字符串改了吗。
- **提示缺 DLL / 生成失败**：NuGet 还原一下，重新生成解决方案，`bin/` 没提交到仓库。
- **忘记密码**：密码是加密后存的，直接进数据库改用户表，别问我。
